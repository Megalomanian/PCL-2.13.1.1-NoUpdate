覆盖安装：3 步完成

不需要卸载，也不需要重新配置游戏目录。

1

完全退出 PCL

关闭 PCL 窗口，并确认任务管理器中没有 PCL 进程。否则 Windows 会锁定 exe，无法替换。

2

重命名并覆盖

把下载的 PCL-2.13.1.1-NoUpdate.exe 重命名为 Plain Craft Launcher 2.exe，拖入原 PCL 文件夹，选择“替换目标中的文件”。

3

启动

双击 Plain Craft Launcher 2.exe。原配置、账号和游戏目录会继续使用。

如果替换时提示“文件正在使用”，说明 PCL 还没有完全退出。请在任务管理器中结束 PCL 进程后重试。

这个版本改了什么

只做最小修改，不改下载源和游戏启动逻辑。

✓

保留 MC 下载

原版 2.13.1.1 的 MC 下载、安装、Mod、整合包、资源包下载功能全部保留。

✓

禁用自动更新

UpdateStart、UpdateRestart、UpdateReplace 置空，无法下载或替换启动器自身。

✓

检查更新只提示

手动点击“检查更新”只显示固定版本提示，不再联网检查，也不会下载更新包。

✓

配置保持不变

覆盖后继续使用原来的 %APPDATA%\PCL 配置和 .minecraft 目录。

常见问题

覆盖安装前建议先看一眼。

为什么不直接覆盖官方 PCL 2.99？

可以直接覆盖。只需先完全退出 PCL，然后把本版本 exe 重命名为 Plain Craft Launcher 2.exe 替换原文件。覆盖后仍使用原有配置和游戏目录。

提示“文件正在使用”怎么办？

PCL 还没有完全退出。关闭 PCL 窗口后，在任务管理器中结束残留的 PCL 进程，再重新替换。

覆盖后需要重新登录或重新设置吗？

不需要。配置、账号、Java 路径和游戏目录都会沿用原来的设置。

这个版本还会自动更新到 2.99 吗？

不会。启动器更新下载、替换和重启流程都已被禁用；点击“检查更新”也只会显示固定版本提示。

这是官方版本吗？

不是。这是基于 PCL 2.13.1.1 正式版的第三方修改版，不代表 PCL 官方或原作者龙腾猫跃的立场。
